Se você veio buscar como registrar as ações do parque, o lugar certo é Como preencher. Esta página trata da administração.

Perfis de acesso

Cada pessoa tem seu próprio usuário e senha, e tudo que ela registra fica marcado com o nome dela. É isso que dá rastreabilidade ao dossiê.

PerfilPode fazerComo atribuir
Gestor Tudo, incluindo configuração do parque e administração de usuários. Grupo Gestor + marcar “Membro da equipe”.
Equipe Registrar ações, evidências, métricas, revisões e empreendimentos. É o perfil do técnico. Grupo Equipe.
Auditor Apenas consultar e gerar o dossiê. Não altera nada. Grupo Auditor.
Para criar os grupos (uma vez só, no servidor): python manage.py criar_perfis. Depois, cadastre as pessoas em Usuários e coloque cada uma no grupo certo.

Primeiros passos em uma instalação nova

  1. Carregar o catálogo CERNE: python manage.py seed_cerne. Traz os 4 níveis, 12 processos, 29 práticas, requisitos e métricas.
  2. Criar o usuário gestor: python manage.py createsuperuser.
  3. Criar os perfis: python manage.py criar_perfis.
  4. Conferir os dados do parque: em Configuração, ajuste nome, cidade e nível almejado.
  5. Cadastrar a equipe: um usuário por pessoa, no grupo Equipe.
  6. Começar a registrar: a equipe usa Registrar ação no dia a dia.

Backup

São duas coisas para salvar, e precisam ser salvas juntas:

  1. O banco de dados — todos os registros, situações, medições e a trilha de quem fez o quê. Use python manage.py backup, que grava em backups/.
  2. A pasta dos arquivos — as evidências anexadas. O caminho aparece em Arquivos e em Configuração.
Backup do banco sem a pasta de arquivos gera um dossiê com evidências quebradas. Salve os dois, na mesma rotina.
